# Работа с ненаправленными графами в среде nanoCAD

Плагин для nanoCAD (MultiCAD.NET API), реализующий построение
ненаправленных графов пользовательскими объектами, поиск кратчайшего
пути между узлами и настройку внешнего вида элементов.

## Требования

- nanoCAD 24 (сборка велась и проверялась под эту версию)
- nanoCAD 26 дополнительно проверялась работоспособность
- .NET 6

## Библиотеки

Проект ссылается на сборки nanoCAD, которые не входят в репозиторий.
Перед сборкой поместите в папку `Libs` следующие файлы из каталога
установленного nanoCAD (одной из версий 24 / 24.1 / 25 / 26):

- `mapinet.dll`
- `mapimgd.dll`
- `MapiBaseTypes.dll`
- `hostmgd.dll`
- `hostdbmgd.dll`

## Команды

| Команда            | Описание                                                        |
|--------------------|-----------------------------------------------------------------|
| `TW_BUILD_CIRCLE`  | Построение графа, где вершины синие круги. Автоматическое соединение ребер с предыдущим узлом. (клик по существующему ребру разбивает его на два) [Esc для выхода] |
| `TW_BUILD_TRIANGLE`| Построение графа, где вершины красные треугольники. Автоматическое соединение ребер с предыдущим узлом. (клик по существующему ребру разбивает его на два) [Esc для выхода] |
| `TW_EDGESTYLE`     | Применить вид выбранного ребра образца ко всем рёбрам           |
| `TW_FINDPATH`      | Найти и подсветить кратчайший путь между двумя узлами           |

## Другие действия

* При удалении вершины автоматически удаляются инцидентные ей ребра.
* Ребра можно удалять отдельно от вершин.
* Форма узла (круг или треугольник) и вид рёбер (цвет, толщина, тип линии) настраиваются через палитру свойств nanoCAD.

## Загрузка

В nanoCAD выполните команду `NETLOAD` и укажите собранную сборку плагина.

## Запуск тестов

Юнит-тесты логики (проекция, алгоритм Дейкстры, геометрия)
не требуют nanoCAD и запускаются командой:

    dotnet test
